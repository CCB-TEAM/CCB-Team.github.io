# Crown-duel

“皇冠对决”是基于卡兹游戏圈事件与人物抽象而成的浏览器决斗游戏。仓库目前包含一个独立的 HTML 文件，其中包含页面、样式和游戏脚本。

## 当前状态

仓库尚无项目 README 或版本说明。可查看源文件了解当前玩法及实现；功能完整性和兼容性以仓库实际内容为准。

## 实现形态

仓库里只有 `duel_merge.html` 一个文件（约 152 KB）。页面结构、样式、卡牌数据与对战脚本都内联在这一个文件里，由此可以直接推出：

| 事实 | 直接后果 |
|---|---|
| 无外部脚本、样式或数据文件 | 打开这份 HTML 就是完整程序；没有构建步骤，也没有需要一起分发的资源目录 |
| 卡牌数据与游戏逻辑同处一个文件 | 改卡或改规则就是编辑 HTML 文本，改完刷新即生效，无需编译或打包 |
| 没有模块拆分 | 迭代以整文件替换进行，改动无法按模块隔离，也无法单独引用其中某个函数 |
| 不是库、也不导出接口 | 其它项目无法把它当依赖引入，只能整页嵌入或整体复制 |

```text
duel_merge.html
  ├─ 页面结构
  ├─ 样式
  ├─ 卡牌数据
  └─ 对战脚本
```

这种形态的取舍很直接：分发与试玩成本几乎为零（给一个文件、用浏览器打开），代价是代码组织、复用与测试都无从下手。仓库也没有 README、构建脚本或测试目录，所以上面的判断只针对文件形态，不涉及玩法规则是否完整或正确。
