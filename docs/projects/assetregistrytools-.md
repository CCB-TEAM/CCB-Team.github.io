# AssetRegistryTools-

这是 [AssetRegistryTool 上游仓库](https://github.com/killmyworld/AssetRegistryTool)的 Fork，提供 Unreal Engine 5.6.1 编辑器插件，用已有注册表和工程中的资产生成 `AssetRegistry.bin`。仓库描述提到支持导入 cooked 资产。

## 用途与边界

README 描述了编辑器界面以及用于列出、合并注册表的 commandlet。生成结果需要在目标游戏中测试：cooked 包元数据和游戏自定义加载行为可能无法仅从编辑器资产推断。
