# Solstice

Solstice 是围绕 Unreal Engine cooked 资产与单向 Kismet 字节码生成的技术概念仓库，汇集架构记录、实施计划、实验和开发提示。

## 项目方向

项目探索以浏览器为入口的资产检查与指定函数字节码生成流程，并强调资产本地引用、写回验证和明确报告不支持的能力。

## 当前状态

仓库将自身标为**概念与早期工程规划**；文档中的规划不代表所有功能都已实现或验证。实际支持范围与阶段进展请以仓库的路线图和兼容性说明为准。
