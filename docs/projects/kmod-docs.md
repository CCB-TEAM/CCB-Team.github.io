# kmod-docs

KMod 加载器的中文文档，涵盖 Windows 与 Android 版本的安装、模组开发和 API。

## 文档与维护

文档使用 mdBook 构建，页面源码位于 `src/`，目录由 `src/SUMMARY.md` 维护。仓库说明通过 GitHub Actions 在推送到 `main` 后构建并发布文档。
